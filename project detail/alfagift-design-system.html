Project Overview

Alfagift Design System (2024)

Alfagift Design System Web is a documentation website used to store and showcase static promotional campaign content modules for Alfagift. The platform provides a centralized reference that is used as a guide in implementing the component for the Alfagift campaign promo.

Role

Frontend Developer

Platform

Desktop, Mobile

Tool

VS Code

Case Study

Problem

As the number of static promotional campaign modules continued to grow, the team needed a centralized documentation platform to organize and showcase these modules in a consistent way. The documentation also needed to provide practical examples of how each module could be implemented, making it easier for the team to understand and reuse the available components.

What did I do?

I was responsible for filling the content of each menu within the web since the main framework has been developed by my mentor initially. I created code snippets for the available promotional modules and developed mobile mockups that could be run as interactive prototypes using React.js. This allowed each module to be documented not only through its code implementation but also through a visual representation of how it would appear and behave within the Alfagift mobile application.
